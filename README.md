# נוגטים / Nougatine

אתר מאפייה וקונדיטוריה בעברית RTL — הר נוף, ירושלים.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Motion
- Lucide icons

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Business copy and contact live under `src/data/`.

Unverified contact fields are marked `verified: false` in `src/data/contact.ts` — update before publishing.
